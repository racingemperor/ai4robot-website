# Website design and content architecture

## Page roles

Home uses the display title Imported Gallery List Exam to introduce the Embodied Generalist Exam manuscript: flowing task wall, identity and three scale figures, paper metadata, News, overview video, introduction, Overall bar board, Citation and shared footer. The Citation section follows LIBERO-Pro2.0's heading, bordered code panel and copy control; it uses confirmed project metadata without inventing paper authors or publication details.

Task is the task collection. Clicking a card animates into a centered floating window. It opens with the task title and objective, then a representative demonstration video, brief task facts and model performance, followed by model/episode recording, synchronized video/input/output/code, paper category, completion checks and evidence in one continuous document. The representative video reuses the Home task clip; individual model recordings remain within their own score rows. No inner tabs or standalone episode/matrix workspace remain. Each model has a compact row with a proportional success bar, numeric score and supporting metrics. Clicking it reveals the synchronized player directly beneath that row, within the same model item. Only one row expands at a time; collapsing pauses its recording and preserves its position. Specific model/episode links open the corresponding row, while ordinary task visits start collapsed. No detached task-recording heading or model selector remains. Step history stays available as an inline disclosure. The per-task success summary covers all valid aggregate trials, independently of the selected video sample.

Leaderboard opens with News, compares six manuscript categories plus Overall in a line chart, then shows the complete 23-task table. Chart model labels/logos are visibility-only checkbox labels. Curves and table identities/scores open a model result window, where each task row expands its synchronized recording in place. Only one task expands; collapsing, changing models or closing pauses it. The six category cards share one compact desktop row, with aligned scores and coverage; tablet and phone layouts use three and two columns. Full category labels wrap naturally without clipping. Model colors, labels and numeric alternatives supplement one another. Missing values are not drawn as zero. Sorting does not change overall eligibility. Data-source, release-wait and ranking-methodology sections are omitted. Optional data controls and scope disclosures do not create separate subpages.

Report follows LIBERO-Pro 2.0’s publication-entry style and contains only publications, project announcements and coverage. The EGE paper uses its own confirmed title; unprovided author/venue/PDF details are omitted. The site announcement describes what is available. External coverage entries are added with their real links. No methods/configurator/FAQ or embedded documentation report is shown. Contribute is a short invitation for new tasks, methods and models, with proposal email drafts addressed to racingemperor@outlook.com. Community is a separate contact page with two QR cards for WeChat/QQ and a GitHub contact link. Its layout follows the reference’s platform titles, invitation cards and full-size image links; no reference-project contact codes are copied.

The fixed header groups the Imported Gallery List Exam identity with Code, Datasets and Community on the left, and the five main pages on the right. Code and Datasets use attributed GitHub/Hugging Face icons; Datasets remains inactive until supplied. Community is independently active within the resource group. Mobile resources remain visible on their own row, separate from the five-link Menu. No secondary page bars or side index are mounted. No header logo artwork is currently rendered; its text matches the Home hero. The manuscript title and citation remain unchanged. Existing section URLs canonicalize to the parent; Episodes links select their task/model directly. Active links work with native modified clicks and browser navigation.

Task and Leaderboard share task-filters.js/css: paper categories, embodiments/scenes and delivery modes, with validation and intersecting filters. Both display Evaluation scope directly, with labels, bordered reset and count. Task adds search and pagination, using eight compact cards per page and three pages for the complete catalog. Desktop uses four columns and two rows; tablets and phones reduce columns for readability. The page controls are centered and omit the visible range caption. The URL restores the page; filter changes start at page one and task/episode links select the matching page. The panel has internal padding and a 30–40px gap before cards/charts. URL state restores the scope, and conflicting task recording links clear it. Pointer focus uses a restrained border while keyboard focus stays explicit.

## Visual and accessibility rules

Use a white canvas, neutral surfaces, dark ink and restrained blue controls, with a complete dark palette. Lato comes from the LIBERO-Pro 2.0 font assets under the included SIL OFL license. Use 16 px body, 18 px introduction and 15 px / 700 navigation, matching the existing site. Code and trace snapshots use monospace. Copy uses available column width and wraps naturally; do not insert decorative line breaks.

Controls and media frames retain soft corners. Keep native labels, visible focus, one H1 per page, a skip link and aria-current on the active primary navigation link. Tables scroll within labeled regions. Small screens stack replay media and traces, retaining a usable range input and 44 px controls. Task windows leave surrounding context visible and return focus to the opening card. Reduced motion skips animated card transforms and scroll entry effects.

Home tiles use original task concepts until footage is supplied. Duplicate wall cycles have distinct SVG IDs and are hidden from keyboard/accessibility output. Videos decode only while visible; page visibility, focus and reduced motion pause the wall. The theme transition fades page snapshots without replacing live recording elements.

## Data and media boundaries

Results.validate is the single normalized-report contract. Official reports and the layout dataset remain separate internally. The public UI has no provenance or release-wait notices. A single eight-model roster supplies real model names, harnesses and official brand logos across all pages. Results.defaultSource displays the layout dataset while the official report is empty. Supplied real reports replace the layout content through the same validated contract. Task layout previews are separate from episode results.

TaskReplay owns active task/model/episode and per-episode playhead positions. Public views use the website report and hosted media, without reading local report storage. Closing/hiding suspends playback. Each report episode can supply a hosted video/poster and timestamped observation images. Only content at or before the playhead appears. The workspace reserves stable space for empty and populated input/output/code states, feedback and observation frames. Video and model input/output share the top row; code and feedback each span both columns below, avoiding unused space beneath the video. Long content scrolls inside keyboard-focusable regions; timestamp updates do not resize the task window content or move the outer scroll position. Mobile stacks the video, fixed-height input/output, code and feedback. Invalid/missing video and clock mismatches are explicit. No robot code is executed.

The six paper categories are robotic manipulation, navigation, scene generation and interaction reconstruction, policy development and training, training data collection, and in-context learning. The user confirmed the October 28 manuscript supersedes the older 22-task/GitHub decision: T18 is restored and T23 becomes training trajectory collection. Task names follow the manuscript figure; unspecified robot brands and numeric thresholds are not invented. The older seven editorial capability dimensions remain retained source annotations, not manuscript taxonomy or measured difficulty. No raw internal manuscript, template author list, unsupported empirical claim or invented press item is published.
